fashe. web app: ready to host
===============================

This folder is the whole app. Upload everything in it (including the hidden
.nojekyll file) to any static host. It works at a site's root or in any
subfolder; no server code, database or build step is needed.

Demo logins (mock data, nothing is saved on a server):
  guest@fashe.lb / Fashe@123
  host@fashe.lb  / Fashe@123

QUICKEST: Netlify Drop (no account needed to try)
  1. Open https://app.netlify.com/drop
  2. Drag this folder onto the page.
  3. Share the link it gives you.

GITHUB PAGES (upload in the browser, no git commands)
  1. Create a new public repository on github.com.
  2. "uploading an existing file" -> drag in everything inside this folder
     (not the folder itself) -> Commit.
  3. Settings -> Pages -> Source: "Deploy from a branch",
     Branch: main, folder: / (root) -> Save.
  4. After a minute it is live at https://<username>.github.io/<repository>/

ON A PHONE
  Open the link in Safari or Chrome, then Share -> "Add to Home Screen".
  It gets the Shanta icon and opens full-screen like an app.

NOTE
  Opening index.html by double-clicking it will NOT work; browsers block it.
  It must be served over http(s). To preview locally:
      python3 -m http.server 8000      (run inside this folder)
      then open http://localhost:8000
